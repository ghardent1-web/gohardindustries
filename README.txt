GO HARD INDUSTRIES LLC WEBSITE

FILES
- index.html: Main website page
- styles.css: Website design and responsive layout
- script.js: Mobile menu, animations and email form

HOW TO VIEW
1. Open index.html in any modern web browser.
2. Internet access is needed for the Google fonts and Pexels photos.

HOW TO PUBLISH
Upload all three files together to your web host's public_html, www or root website folder.
You can also deploy the folder with services such as Netlify, GitHub Pages, Squarespace custom code or traditional hosting.

CONTACT FORM
The form opens the visitor's email program and sends to ghardent1@gmail.com.

IMPORTANT CUSTOMIZATION
Replace or add your own project photos at any time by editing the image URLs in styles.css.
